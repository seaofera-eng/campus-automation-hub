# 넣어야 할 이미지 목록

> 2026-08-27 · 리뷰 2026-08-26 2절 반영
>
> 랜딩과 마법사에 들어갈 그림입니다. **아직 아무것도 안 넣어도 화면은
> 정상으로 돕니다.** 그림이 들어갈 자리에 회색 네모와 필요한 크기가
> 표시되어 있고, 파일을 넣으면 그 자리에 그대로 들어갑니다.

---

## 넣는 법

1. 파일을 `public/landing/` 에 아래 이름 그대로 넣습니다.
2. 코드에서 `src` 를 연결합니다. (한 줄씩, 제가 해 드립니다)

```
public/landing/
  hero.png
  wizard-step-1.png
  wizard-step-2.png
  wizard-step-3.png
  wizard-step-4.png
  wizard-step-5.png
```

`public/` 폴더는 아직 없습니다. 파일을 주시면 그때 만들겠습니다.

---

## 크기

**표에 적힌 크기는 실제 파일의 픽셀 크기입니다.** 화면에 보이는 것보다 2배로
잡았습니다 — 요즘 노트북 화면은 픽셀이 촘촘해서, 보이는 크기 그대로 만들면
흐리게 보입니다.

| 파일                 | 크기 (px)     | 비율 | 화면에서 보이는 크기 | 들어가는 곳                    |
| ------------------ | ----------- | -- | ----------- | ------------------------ |
| `hero.png`         | **840 × 630** | 4:3 | 420 × 315   | 랜딩 첫 화면 오른쪽              |
| `wizard-step-1.png` | **640 × 640** | 1:1 | 260 × 260   | 마법사 1단계 "무슨 일을 하고 싶나요?"  |
| `wizard-step-2.png` | **640 × 640** | 1:1 | 260 × 260   | 마법사 2단계 "어떤 자료를 사용하나요?"  |
| `wizard-step-3.png` | **640 × 640** | 1:1 | 260 × 260   | 마법사 3단계 "어떤 결과가 필요하나요?"  |
| `wizard-step-4.png` | **640 × 640** | 1:1 | 260 × 260   | 마법사 4단계 "얼마나 자주 하나요?"    |
| `wizard-step-5.png` | **640 × 640** | 1:1 | 260 × 260   | 마법사 5단계 "중요한 조건이 있나요?"   |

비율만 맞으면 크기는 조금 달라도 됩니다. **비율이 다르면 잘리거나 늘어납니다.**

## 그림에 담을 내용

각 단계가 무엇을 묻는지를 그림으로 한 번 더 말해 주는 역할입니다. 글로 이미
설명하고 있으니 **장식에 가깝게**, 복잡하지 않게 가는 편이 낫습니다.

| 자리       | 이런 그림이면 맞습니다                                    |
| -------- | ----------------------------------------------- |
| 랜딩 대표    | 교내 구성원이 반복 업무를 자동화에 넘기는 장면. 학교 느낌이 나면 좋습니다      |
| 1단계 하는 일 | 여러 종류의 업무 아이콘이 흩어져 있는 그림                        |
| 2단계 자료   | 문서·엑셀·PDF·메일 같은 파일 더미                           |
| 3단계 결과   | 정리된 표, 요약된 문서, 알림 같은 결과물                        |
| 4단계 주기   | 달력이나 반복을 뜻하는 그림                                 |
| 5단계 조건   | 자물쇠, 확인 도장처럼 "조심해야 할 것"을 뜻하는 그림                 |

## 지켜야 할 것

- **배경을 투명(PNG)으로** 주세요. 화면 바탕색이 흰색과 연회색 두 가지입니다.
- **글자를 넣지 마세요.** 화면에 이미 한국어 설명이 있고, 그림 속 글자는
  화면 낭독기가 읽지 못합니다.
- **색은 파랑 계열**(`#164a9b` 충남대 파랑)을 기준으로 부탁드립니다.
  강조가 필요하면 자홍(`#c52a7a`)을 조금만 씁니다.
- 파일 하나가 **500KB 를 넘지 않게** 해 주세요. 시연 자리에서 망이 느릴 수
  있습니다.
