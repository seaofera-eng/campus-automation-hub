## 0. 시작하기 전에

### 서버 띄우기

```powershell
pnpm demo:reset     # 데모 데이터 초기화 (리뷰 중 뭘 눌러도 되돌릴 수 있습니다)
pnpm dev            # http://localhost:3000
```

### 데모 계정

비밀번호가 없습니다. 로그인 화면에서 카드를 누르면 바로 들어갑니다.


| 이름  | 역할  | 소속     | 이 계정으로 봐야 하는 것           |
| --- | --- | ------ | ------------------------ |
| 김개발 | 개발자 | 정보화본부  | 도구 등록·수정, 개선 요청 처리       |
| 정연구 | 개발자 | 연구지원과  | 남의 도구가 안 보이는지            |
| 이검토 | 검토자 | 정보화본부  | 검토 큐, 위험 체크리스트, 수요-도구 연결 |
| 박수요 | 수요자 | 학사관리과  | 수요 등록, 평가, 개선 요청         |
| 한상담 | 수요자 | 학생상담센터 | 남의 수요가 어떻게 보이는지          |
| 최관리 | 관리자 | 정보화본부  | 관리 메뉴 전체, 감사 로그          |


### 채우는 법

- 판정 칸의 `⬜` 중 해당하는 것을 `✅` 로 바꿔 주세요.
- **판단이 어려우면 `애매` 에 표시하고 메모에 왜 걸리는지만 적어 주세요.** 제가 선택지를 정리해 다시 여쭙겠습니다.
- 메모는 짧아도 됩니다. "글씨 작음", "여기 뭘 눌러야 할지 모르겠음" 정도면 충분합니다.
- 화면을 캡처해 두셨다면 `docs/review-shots/` 에 넣고 파일명을 메모에 적어 주세요.

### 우선순위 기준


| 표시   | 뜻              |
| ---- | -------------- |
| `높음` | 이대로 시연하면 곤란하다  |
| `보통` | 고쳐야 하지만 시연은 된다 |
| `낮음` | 여유 있을 때        |

**공통에서 고쳐 주세요**

- 첫화면을 [대시보드]가 아니라 랜딩페이지가 따로 존재했으면 좋겠음. 랜딩페이지 기능은  [추천도구], [인기도구] 등 '도구 파트'와 [최신 수요 요청]. [인기 수요], 등 '수요 파트'가 이 노출되어 있어 접근성을 높이고, 쉽게 도구를 사용해보고 수요를 작성해볼 수 있도록 하는 기능을 갖음. 그리고 전반적인 이용 가이드를 안내할 필요가 있음. [공지게시판]도 생성해서 노출. 랜딩페이지의 이미지 에셋은 따로 제공할 예정으로, 디자인보다 기능만 우선 구현
- [대시보드]에서 [부서별 도구] 항목이 필요 없음. [보유 토큰]을 표기
